# KAGEROU-NET

VIVANTの解析画面のような雰囲気で作った、ブラウザで動く多機能ツールです。
「国家データ解析ターミナル」を模したデザインの中に、日常使いできる秘書ツール(TODO・メモ・タイマー・単位換算)をまとめています。

> ⚠️ 解析ビューに表示されるセクター名・数値はすべて架空のデモデータです。実在の国・地域とは一切関係ありません。

## ファイル構成

```
kagerou_terminal.html   本体(このファイル1つだけで動作します)
README.md               このファイル
```

外部ライブラリのインストールは不要です。`kagerou_terminal.html` をブラウザで開くだけで動きます。

## 使い方

1. `kagerou_terminal.html` をブラウザ(Chrome / Safari 推奨)で開く
2. 画面上部のタブで機能を切り替える

| タブ | 内容 |
|---|---|
| 解析 | レーダー画面に架空のセクター(TALON、VESPERなど)を表示。クリックすると詳細データ(経済指数・情勢安定度など)とログが更新される |
| TODO | タスクの追加・完了チェック・削除 |
| MEMO | 自由記述メモ。入力後、自動で保存される |
| TIMER | ポモドーロ式タイマー(作業25分 / 休憩5分の切り替え) |
| 換算 | 11カテゴリの単位換算(下記参照) |

## 対応している単位換算カテゴリ

- 長さ(mm / cm / m / km / インチ / フィート / ヤード / マイル / 海里)
- 重さ(mg / g / kg / t / oz / lb)
- 温度(℃ / ℉ / K)
- 面積(cm² / m² / km² / 坪 / 畳 / エーカー / ha)
- 体積(ml / L / m³ / カップ / ガロン(US) / 合 / パイント)
- 速度(m/s / km/h / mph / ノット)
- 時間(秒 / 分 / 時間 / 日 / 週)
- データ容量(B / KB / MB / GB / TB / KiB / MiB / GiB)
- 圧力(Pa / hPa / kPa / atm / bar / mmHg)
- 角度(度 / ラジアン / グラード)
- エネルギー(J / kJ / cal / kcal / Wh / kWh)

## データの保存について

TODOとMEMOの内容は、このツールを開いているブラウザ内(Claudeのストレージ機能)に保存されます。同じ環境で再度開けば内容は残りますが、他の人やブラウザとは共有されません。

## カスタマイズしたいとき

- 解析ビューのセクター情報は、HTML内の `sectors` 配列(JavaScript)を編集すると変更できます
- 換算の単位・カテゴリは `UNIT_DB` オブジェクトを編集すると追加・変更できます
- 配色は `:root` 内のCSS変数(`--green` `--amber` `--red` など)で一括変更できます

## 技術メモ

- 単一HTMLファイル(CSS・JavaScript含む)、React等のビルド不要
- フォントは Google Fonts(Rajdhani / Zen Kaku Gothic New / JetBrains Mono)をCDN経由で読み込み
- スマートフォン幅では解析ビューが3段の縦積みレイアウトに切り替わります
